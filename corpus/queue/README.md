# Show lists (Kingsley, 2026-09-27)

`make ingest LIST=<file>` studies the shows in a list: one note per show in `notes/`, shows that already have a
note are skipped.

- **Versions:** a year in parentheses picks the version (`Berserk (1997)`); otherwise the most-watched adaptation.
- **Print titles:** write `(manga)` (or `manhwa`, `webtoon`, `light novel`) to force the print original; without
  it, a screen version is picked when one exists.
- **Lists:** `priority_1.txt` (studied 2026-09-27), `print_first.txt` (Jagaaan, Choujin X), `donghua.txt`,
  `priority_2.txt` (not yet studied).
