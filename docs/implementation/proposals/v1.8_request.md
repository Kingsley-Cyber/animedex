# v1.8 request (Kingsley, 2026-09-27, verbatim)

This is the consolidated request. It supersedes every earlier v1.8 message and addendum. The plan is in `CHANGE_PLAN_v1.8.md`.

---

CHANGE v1.8 (CONSOLIDATED): concept, character, and abstract layers.
Supersedes every earlier v1.8 message and addendum. Plan it with v1.7 (gather-first) and land
both before any M3 live runs. Then re-extract the 14 titles already in the corpus for the new
fields (partial re-runs only; don't redo unchanged work), and make `make backfill` capture all
of this for every new title. Every new field is an enum or a short list, gets vocab entries
and at least one CQ, and every gathered value keeps its source URL.

SOURCING
- GATHER (cheapest subscription model, web search + fetch) collects documented facts:
  ability and technique lists, forms, backstories, institutions, endings, reception. Scope
  rule: wikis mix in manga-only content; keep only what is inside the title's scope.
- INTERPRET (strong model, no web) fills every analysis field from the gathered facts, atoms,
  and character records.
- Word caps: phrases ≤12 words, sentences ≤25 words, unless a field says otherwise.

1. POWER SYSTEM (power_combat, per title)
   - mc_edge: how the protagonist is legibly the strongest. biggest_number,
     creative_reinterpretation (power used as a medium, beyond its design),
     partnership_with_power, unique_cost (pays what nobody else will), relentless_training,
     hidden_advantage, not_strongest, other.
   - power_embodiment: energy_or_technique, bound_entity (a power with its own history and
     character), object_or_artifact, system_interface, body_transformation, other.
   - set_structure: closed_set (fixed roster, e.g., nine tailed beasts), hierarchical (a base
     set with sub-disciplines, e.g., bending → lightning, bloodbending, metalbending),
     open_variety (every user unique, e.g., devil fruits, quirks), pantheon (a roster of
     mythic or historical beings), universal_energy (one shared energy, many techniques),
     unique_to_few, none, other.
   - subset_mechanics (multi): specialization (a sub-skill of one base), combination (two
     bases fuse into a new one), forbidden_art (a taboo sub-skill), bloodline (inherited by
     lineage), legendary_unlock (rare or lost), none.
   - set_scaffold: arbitrary (numbers or labels), cultural_reference (a scaffold the audience
     already knows: tarot, zodiac, sins, myth), semantic_domain (powers built from domains of
     meaning), elemental, none, other.
   - member_depth: label_only, ability_only, identity_with_history.
   - world_integration: decorative, social_structure, economic, political_geography,
     cosmological, other.
   - rarity: universal, common, rare, unique_to_mc.
   - power_up_mode (multi): none, staged_forms (gears, Super Saiyan, Shikai → Bankai),
     temporary_boost (a short burst with a cost), awakening (a one-time unlock),
     partnership_mode, domain (the user rewrites the battlefield), other.
     Plus power_up_cost (≤15 words).
   - fight_logic (multi): power_level, type_counters, rules_exploitation (vows, restrictions,
     conditions), strategy_information, emotional_surge, sacrifice, other.

2. STORY ENGINE (core, per title; any medium)
   - story_engine (primary + optional secondary): tournament, journey_quest, ladder_climb,
     investigation, war_campaign, death_game_rounds, monster_of_the_week, survival,
     political_intrigue, revenge, slice_of_life, other.
   - pilot_hook_type: cold_open_action, mystery_hook, tragedy_inciting, power_awakening,
     transported, status_quo_disruption, other.
   - ending_type (finished stories only): triumphant, bittersweet, tragic, open, unfinished,
     other.

3. WORLD ENGINE (core, per title)
   - setting_type: modern_urban, historical, secondary_fantasy, isekai, future_scifi,
     post_apocalyptic, other.
   - world_visibility: hidden (a masquerade the public doesn't know), open, contained.
   - conflict_scale: personal, local, national, world, cosmic.
   - institutions (up to 3): name + type (academy, military, guild_or_license, government,
     criminal_org, religious, other) + role in the story (≤12 words).

4. MC AND CAST (core, per title)
   - mc_archetype: underdog, chosen_one, prodigy, villain_protagonist, everyman,
     already_overpowered, veteran, other.
   - mc_start: weakest, below_average, average, strong, overpowered.
   - mc_goal_type: find_someone, revenge, become_the_best, protect, escape_or_survive,
     change_the_world, restore_what_was_lost, other.
   - ensemble_size: solo, duo, trio, team, large_ensemble.
   - rival_type: friend_rival, antagonist_rival, mirror_rival, none.
   - threat_structure: single_final_boss, escalating_ladder (a boss per arc),
     rotating_threats, society_itself, other.

5. CHARACTERS (new record: characters.jsonl; up to 4 per title: protagonist, main rival,
   main antagonist, mentor or deuteragonist)
   Base fields: role; origin (≤25 words); wound (the formative loss or event, ≤15 words);
   want; need; flaw + condition; moral_line + condition; relationship_to_power (mc_edge
   enum); origin_power_link (origin_creates_power, origin_shapes_use, origin_sets_cost,
   unrelated, other); arc_type (positive_change, flat, fall, corruption, disillusionment,
   redemption, other); backstory_reveal (upfront, gradual, late_twist, never); up to 3
   turning points, each with an episode locator.
   Power kit (for up to 3 powered characters, protagonist first):
   - power_kind: medium (a substance or concept to manipulate), stat_block (a fixed ability
     list), technique_system, bound_entity, object, system_interface, skill_or_trait (a
     non-supernatural edge like intellect or gambling), none.
   - medium (≤6 words); functions (3–6 core affordances); tools (up to 5 signature
     applications, each naming the function it exploits); limits (weaknesses and
     restrictions); forms (up to 5 named stages, each with its trigger and cost).
   - creativity_level: literal, inventive, transcendent. Backed by creativity_moves: up to 3
     uses beyond the power's obvious design, each ≤15 words, with a source.
   - evolution (≤20 words): how the kit grows over the story.
   - For stat_block characters, drama_source instead of creativity: restraint,
     vulnerability, corruption, isolation, other.
   Villain fields (antagonist roles): villain_type (ideological, predator, mirror_of_mc,
   system_or_institution, tragic, hidden_manipulator, nihilist, force_of_nature, other);
   villain_reveal (upfront, gradual, betrayal_twist, never_fully); relation_to_mc (mirror,
   opposing_ideology, obstacle, personal_betrayal, other).
   P2 may cite character records as evidence for atoms.

6. ABSTRACT LAYER (core, per title; INTERPRET only)
   - thematic_argument: thesis_mc (≤15 words), antithesis_villain (≤15 words), resolution
     (≤20 words, what the ending argues).
   - audience_promise (≤15 words) and promise_mechanism (≤20 words). Mixed/flop titles also
     get promise_break (≤20 words, with a source).
   - escalation_model: vertical_power, horizontal_tools, stakes_over_power,
     structural_reset, cost_scaled, none, other.
   - anticipation_hooks (up to 3): hook (≤12 words) + type (promised_payoff, countdown,
     rematch, reunion, long_mystery, next_form).
   - premise_abstraction (≤20 words, no names or medium words). Use it, not the surface
     premise, as the primary text for clone-check similarity.
   - real_world_isomorphism (≤12 words): the real system the mechanics mirror.
   - core_fantasy (multi): secret_strength, underestimated_then_vindicated, mastery,
     found_family, revenge, transgression, being_chosen, protection, freedom, competence,
     other.
   - genre_move: subversion, synthesis, escalation, purification, inversion,
     return_to_basics, other; plus reacts_against (≤12 words).

7. FAILURE PATTERNS (outcomes; mixed/flop titles only; multi, each with a source)
   promise_broken, power_scaling_collapse, villain_deflation, cast_bloat, pacing_collapse,
   adaptation_compression, tone_whiplash, protagonist_passivity, ending_failure,
   production_quality, other. Pre-mortems and graveyard warnings cite these.

8. ABSTRACTION LADDER (P4) AND PRINCIPLE TEST (M7)
   - Each transfer atom gains: mechanism (≤20 words), principle (≤25 words, in the form
     "when X, do Y, because Z"), and anti_pattern (the failure it prevents, ≤12 words).
     Existing essential/variable/failure conditions stay.
   - A principle on an M7 pattern card is marked "predictive" only if it explains at least
     one load-bearing atom in a held-out title it wasn't extracted from. Only predictive
     principles feed ideation as principles.

9. IDEATION
   - Idea cards gain: the MC's edge, origin, wound, and origin-power link; the MC's power kit
     (kind, medium, functions, 3 signature tools, limits, creativity path); thematic
     argument; audience promise; escalation model; core fantasy; premise abstraction.
   - Optional steering brief for `make ideas`: rules I pass as hard constraints (e.g., "the
     MC is legibly the strongest without holding the biggest number"). Ideas that don't
     satisfy the brief are rejected before scoring.
   - Offer mc_edge, story_engine, and mc_archetype as alternative gap-map dimensions.
   - Census: add set_structure, story_engine, and mc_archetype to the census fields so gap
     counts cover them.

10. CQs (write at least one per new field; examples)
   - Which mc_edge types appear in hits, and which gate × mc_edge combinations are unused?
   - Which open_variety systems give the MC a "weak" medium that gets reinterpreted?
   - Which closed or hierarchical sets have identity_with_history members, and on what scaffold?
   - Which power_kind × creativity_level combinations are unused?
   - How do stat_block heroes generate drama in hits vs. flops?
   - Which origin-power links recur in hits' load-bearing atoms?
   - Which story engines have never been paired with bound-entity powers?
   - Which villain types appear with hidden worlds, and which are unused there?
   - Which core fantasies pair with which story engines in hits?
   - Which flops broke the promise their premise made, and how?
   - Which escalation models survive 100+ episodes?
   - Which real-world systems have never been used as power systems?
   - Which premise abstractions have zero near-neighbors?

LEAN RULE: this completes the V1 lens. No further fields until blind review #1 shows where
the ideas are weak.
